# Velox Releases & Distribution

Official public release repository for [Velox](https://github.com/paulnathanielsango/velox), the high-performance macOS gaming translation engine and launcher for Windows DirectX 11/12 games on Apple Silicon.

## 🚀 Download Velox for macOS

Download the latest release for Apple Silicon (macOS 14.0 Sonoma or later):

* **[Download Velox.dmg (Latest)](https://github.com/paulnathanielsango/velox-releases/releases/latest/download/Velox.dmg)** — Standard macOS disk image installer.
* **[Download Velox.zip (Latest)](https://github.com/paulnathanielsango/velox-releases/releases/latest/download/Velox.zip)** — Raw application bundle archive.

---

## 🛠️ Installation

1. Download **`Velox.dmg`** above.
2. Double-click the downloaded `.dmg` file to mount it.
3. Drag **`Velox.app`** into your **`Applications`** folder.
4. Launch **Velox** from Launchpad or Spotlight.

---

## 🔄 Updates

Velox includes a built-in pre-flight auto-updater. When a new version is released, the app will automatically notify you and update in place.
